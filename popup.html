이번 버전은 한 번만 기존 방식으로 설치하세요. 이후 보조 프로그램을 연결하면 압축 해제·덮어쓰기·확장 새로고침이 자동 처리됩니다.

macOS 보조 설치 앱 · Windows 보조 설치 프로그램

  1. 모든 채널을 중지하고, 보조 설치 파일의 압축을 풀어 실행하세요.
  2. 아래 확장 ID를 복사하고 현재 확장에 등록된 설치 폴더를 선택하세요. 설정 백업을 먼저 권장합니다.
  3. 설치 완료 후 아래 연결 버튼을 누르고 권한을 허용하세요.

Git 개발 폴더·연결 폴더는 지원하지 않습니다. 브라우저와 프로필마다 별도 설치 폴더를 사용하세요. 설치 앱은 개발자 서명/공증이 없어 OS에서 실행 확인이 필요할 수 있습니다. 보안 설정을 자동으로 해제하지 않습니다.

보조 프로그램을 최초 한 번 연결하세요.

채널 실행 중이거나 미확인 전송·남은 초안이 있으면 기다립니다. 모두 중지하고 초안을 정리하면 자동 적용하며, 채널을 임의로 다시 시작하지 않습니다.

오류 알림

전체 로그를 건수·기간 제한 없이 누적합니다. 브라우저 저장 공간 한도가 적용됩니다. 채팅방·탭 식별 ID를 포함하며 설정 문구와 입력창 초안을 포함합니다. 인증키는 제외합니다.

알림 설정 확인 중…

알림 사용 안내 · 알림이 보이지 않을 때

이 버튼은 현재 PC의 운영체제 알림을 테스트합니다. Discord 채팅 알림이나 GitHub 빌드 알림과는 별개입니다. 오류 알림을 꺼둔 상태에서도 테스트할 수 있습니다.

  1. macOS: 시스템 설정 → 알림 → 사용 중인 Google Chrome 또는 Brave Browser → 알림 허용 및 배너/알림 스타일을 켜세요. Chrome 항목이 여러 개라면 현재 실행한 앱에 해당하는 항목을 확인하세요.
  2. Windows: 설정 → 시스템 → 알림에서 브라우저 알림을 허용하세요.
  3. 집중 모드·방해금지를 끄고 알림 센터도 확인하세요. 화면 공유·화면 미러링 중에는 알림이 숨겨질 수 있습니다. 공유를 종료한 상태에서도 테스트해 보세요.
  4. 알림을 클릭하면 사용 가이드가 열립니다. 자동 오류 알림은 위 체크박스로 켜고 끌 수 있습니다.

브라우저는 운영체제가 배너를 실제로 보여줬는지 확장 프로그램에 알려주지 않습니다. 테스트 결과와 마지막 알림의 허용·생성·등록 상태는 진단 로그에 포함됩니다.

설정 백업·복원

업데이트는 기존 설치 폴더에 덮어쓰고 확장 프로그램을 새로고침하세요. 다른 폴더·PC로 옮길 때는 백업 파일을 사용하세요.

저장된 채널·문구·주기·내 사용자 ID·A/B 차례를 옮깁니다. 복원하면 현재 채널 설정을 교체하며 자동 시작하지 않습니다. 메일 연결 키는 포함하지 않습니다.

연결된 Discord 채널이 없습니다.

목록을 고르지 않고 연결을 누르면 이 사이드패널이 열린 창의 현재 Discord 탭을 연결합니다. 실행할 때는 채널마다 별도 전송용 창을 포커스 전환 없이 열고, 재시작하면 재사용합니다. 전송용 창은 최소화하지 마세요. 입력 중인 설정은 먼저 저장하세요.

다음 A

입력창에 저장된 A/B 공지가 남아 있으면 현재 차례와 비교해 그대로 보내거나 교체합니다. 그 외 초안은 보존하고 중지합니다.

일반 텍스트와 일반 URL을 지원합니다. 서식이 있는 Markdown이나 커스텀 이모지는 전송 결과 확인을 위해 일시 중지될 수 있습니다.

게시 완료 확인은 생략하지만 Enter 후 최대 3초 동안 입력창이 비워지는지 확인합니다. 문구가 남으면 차례를 유지하고 다음 주기에 게시 기록을 검사한 뒤 최대 3회 재시도합니다. 입력창이 비워져도 서버의 최종 게시 성공을 보장하지는 않습니다.

초

30초–86,400초. 시작하면 다음 메시지를 바로 전송하고, 성공한 뒤부터 이 간격으로 반복합니다.

개발자 모드에서 내 프로필의 사용자 ID를 복사하세요. 비워두면 화면의 프로필 이미지와 전송 상태로 확인합니다.
