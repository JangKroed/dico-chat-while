처음부터 차근차근, DICO 사용법

채널 연결부터 반복 전송까지. 실제 설정과 실행은 Chrome 오른쪽 위 DICO 팝업에서 진행하세요.

어디에서 설정하나요?

Chrome의 퍼즐 아이콘 → Dico While

도구 모음에 Dico While을 고정하면 다음부터 D 아이콘으로 바로 열 수 있습니다. 이 페이지는 사용법을 설명하며 실행 상태를 표시하지 않습니다.

처음 설정시작과 중지여러 채널오류 대처업데이트알림과 이메일

01 · 처음 설정

채널을 연결하고 문구를 저장하세요

  1. Chrome에서 Discord에 로그인하고 메시지를 보낼 채팅방을 엽니다.
  2. DICO 팝업을 열고 기본으로 만들어진 채널 1을 선택합니다.
  3. Discord 탭 연결 → 연결을 누릅니다. 목록을 선택하지 않으면 현재 Discord 탭의 채팅방을 연결합니다. 표시된 채팅방 이름을 확인하세요.
  4. 메시지 A·B와 전송 간격을 입력하고 이 채널 설정 저장을 누릅니다.

문구는 각각 1~2,000자, 간격은 30~86,400초입니다. 처음에는 서식 없는 일반 텍스트로 확인하세요. 제목·목록·이모지 등은 게시 화면에서 달라져 전송 확인에 영향을 줄 수 있습니다.

02 · 시작과 중지

시작하면 먼저 보내고, 그다음 기다립니다

A 전송 → 설정한 간격 → B 전송 → 설정한 간격 → A 전송

시작을 누르면 별도의 전송용 창이 열립니다. 같은 전송용 창이 남아 있으면 재사용하며, 닫힌 경우 다시 시작할 때 새로 엽니다.

  • A가 전송 확인된 뒤 중지했다면 다음 시작은 B부터 이어집니다.
  • 전송용 창은 다른 창 뒤에 두어도 되지만 최소화하거나 다른 채팅방으로 이동하지 마세요.
  • Chrome을 종료하거나 PC가 잠들면 정상적인 반복 전송을 유지할 수 없습니다.
  • 문구나 주기를 바꿀 때는 해당 채널을 중지하고 저장한 뒤 다시 시작하세요.

03 · 여러 채널

채팅방마다 문구와 간격을 따로

  1. 보낼 다른 채팅방을 Chrome에서 엽니다.
  2. 팝업의 + 채널 추가를 누르고 새 항목을 선택합니다.
  3. 해당 Discord 탭을 연결한 뒤 문구와 간격을 저장합니다.
  4. 채널별 시작·중지 또는 모두 시작·모두 중지로 제어합니다.

같은 서버의 서로 다른 채팅방은 각각 등록할 수 있습니다. 동일한 채팅방을 중복 등록할 수는 없습니다. 한 채널에 오류가 나면 해당 채널 상태를 확인하세요.

04 · 오류가 났을 때

게시 여부를 먼저 확인하세요

전송 결과가 불확실하다고 나와요

대상 채팅방에서 실제 게시 여부를 확인하세요. 게시됐다면 팝업에서 전송됨을 선택합니다. 게시되지 않았다면 남은 초안을 지운 후 초안을 지웠고 전송 안 됨을 선택합니다. 결과가 불명확한 상태에서 재전송하지 마세요.

문구가 타이머 전에 입력돼요

반복 예약 3초 전에 문구를 준비합니다. 입력이 안정적인지 확인하고, 예약 시각 이후 다시 검사한 뒤 Enter만 보냅니다. 준비가 늦으면 전송도 늦춥니다. 준비한 내용을 수정하면 자동 전송이 중지될 수 있습니다. 시작 버튼은 즉시 입력 준비부터 수행합니다.

전송 결과가 불확실해요

게시 기록을 최대 3회 다시 확인합니다. 본인의 새 게시가 하나로 확인되면 남은 초안도 A/B와 비교합니다. 이미 게시된 문구는 다음 예약 때 다음 문구로 교체하고, 다음 차례 문구는 그대로 재사용합니다. 개인 초안이나 순서가 불명확한 게시 기록은 자동 처리하지 않습니다. 재확인 중에는 메시지를 다시 보내지 않습니다. 본인 ID를 감지하지 못하면 팝업에 내 Discord 사용자 ID를 입력하세요. 근거가 부족하면 확인 필요 상태를 유지합니다.

슬로우 모드가 있는 채널

채널 연결·실행 시 슬로우 모드 안내 시간을 읽으면 3초를 더해 최소 주기를 적용합니다. 예: 10분 제한 → 최소 603초. 기존 주기가 더 짧으면 자동으로 올립니다. 화면의 남은 제한 시간을 인식하면 문구 차례를 유지하고 대기합니다. 팝업에 ‘슬로우 모드 대기’가 표시되며 최소 30초 뒤 다시 확인합니다. 화면 구조에 따라 제한 시간을 인식하지 못할 수 있으므로 전송 주기는 채널의 제한 시간보다 여유 있게 설정하세요.

여러 채널의 타이머가 밀려요

채널별 전송과 복구는 독립 실행됩니다. 한 채널이 확인을 기다려도 다른 채널은 계속 진행합니다. 각 주기는 전송 확인이 끝난 뒤부터 계산되며, Discord 응답이나 Chrome 상태에 따라 실제 게시까지 시간이 더 걸릴 수 있습니다.

입력창에 문구가 남아 있어요

저장된 A/B 공지는 현재 차례에 맞춰 그대로 보내거나 교체합니다. 전송 후 문구만 남고 새 게시 흔적이 없으면 다음 주기에 최대 3회 재시도합니다. 그 외 초안·게시 흔적·통신 단절은 중지 후 확인이 필요합니다. Discord의 오류 안내와 게시 기록을 확인하고, 팝업의 진단 로그 다운로드로 오류가 난 기기의 로그를 저장하세요. 가능하면 초안을 지우기 전에 화면도 기록하세요.

로딩 화면에서 멈춰요

전송 전 로딩 오류는 최대 10회 새로고침으로 복구를 시도합니다. 모두 실패하면 로그인·채널 접근 권한·네트워크를 확인하세요. 이미 입력한 메시지의 결과가 불확실하면 자동 새로고침하거나 다시 보내지 않습니다.

다른 페이지로 이동했다거나 연결이 끊겼다고 나와요

전송용 창의 채팅방과 로그인 상태를 확인하세요. 업데이트 직후에는 확장 프로그램과 전송용 Discord 페이지를 새로고침하세요. 팝업의 연결 오류가 지속되면 진단 로그와 오류 화면을 함께 전달하세요.

05 · 업데이트와 PC 이동

다시 입력하지 않도록 백업하세요

  1. 팝업에서 모두 중지하고 미확인 전송을 정리한 뒤 설정 백업을 누릅니다.
  2. 업데이트 파일은 기존 설치 폴더에 덮어씁니다. 기존 확장 프로그램을 삭제하거나 새 폴더로 다시 등록하지 마세요.
  3. Chrome 확장 프로그램 관리 화면에서 Dico While을 새로고침합니다.
  4. 다른 PC에서는 팝업의 백업에서 복원으로 파일을 선택한 뒤 내용을 확인하고 시작합니다.

백업에는 채널·문구·간격·내 사용자 ID·다음 A/B 차례가 포함됩니다. 복원은 기존 설정을 교체하며 자동 시작하지 않습니다. 이메일 연결 키는 별도로 설정해야 합니다.
