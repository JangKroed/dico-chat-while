# 자동 이메일 제보 보안 점검·보강

기준: main cf18098(0.4.42), 탐지 커밋 66f7df4. 업데이트 PR #2와 별도 브랜치에서 진행한다.

1. 제출 키의 권한, 고정 수신자, Apps Script 권한 경계와 기존 동의·로그 필터를 대조한다. 실제 키는 출력하지 않는다.
2. 실제 Central.gs를 VM에서 실행하고 MailApp/Properties/Lock 경계만 대체해, 위조 보고서·크기 제한·비밀 필드·반복 제출을 재현한다. 실메일은 보내지 않는다.
3. Central.gs에 UTF-8 요청/첨부 한도, 구조 검증·민감 필드 제거, 영속적인 짧은 구간 발송 제한·일일 바이트 예산·긴급 차단을 적용한다. 기존 일일 20건/90일 영수증/모호한 발송 중복 방지는 유지한다.
4. 클라이언트는 새 중계 거절 코드를 고정 메시지로 표시한다. 서버 응답·예외 원문을 로그나 전송 상태에 넣지 않는다.
5. 보안 회귀·전체 테스트·기존 정적 검사를 수행한다. 검증 범위/남은 남용 위험/배포 및 GitGuardian 확인 한계를 문서화하고 GitHub PR로 반영한다.

범위 밖: Discord 발송 엔진, 업데이트 복구, 사용자 운영 설정 변경, 실제 발송 부하 시험. 공개 키 교체만으로 인증 효과가 생긴다고 주장하지 않는다.
