# 브라우저별 전송 창과 연결 재확인

사용자 요청: 브라우저마다 전송용 창 하나에 채널별 탭을 모으고 평소에는 최소화한다. 대시보드와 로그에서 문제가 생긴 채널을 선택하면 기존 탭을 앞으로 가져온다.

선택한 구현은 Chromium 확장 API의 일반 창·탭을 유지하는 방식이다. 창을 닫는 방식은 Discord DOM 실행을 중단하고, 별도 headless 브라우저는 기존 로그인과 실행 환경을 바꾸므로 사용하지 않는다. 최소화는 화면 정리이며 브라우저 프로세스는 계속 실행돼야 한다. 백그라운드 절전이나 사이트 변경으로 실행이 차단되면 기존 안전 검사를 유지한다.

- 신규 채널은 소유권이 확인되는 공용 전송 창의 비활성 탭으로 연다.
- 기존 여러 창은 명시적인 ‘전송 창 모으기’ 요청으로 정리한다. 해당 브라우저의 모든 그룹 중지 및 미확인 결과 정리가 선행돼야 한다. 탭 ID와 초안을 유지하고 일반 탭은 이동·최소화하지 않는다.
- 보기는 기존 연결된 Discord 탭만 활성화한다. 로그인·대상 문제가 있어도 해당 기존 탭을 보여줘 점검할 수 있게 한다. 새 탭 생성, 페이지 이동, 발송은 수행하지 않는다.
- 숨기기는 모든 탭이 관리 대상인 창만 최소화한다.
- 관측 작업을 직렬화·병합하고, 읽기 실패를 실제 계정 불일치와 구분한다. 검증 불가 상태에서는 발송을 막는다.
- 현재 세션에서 장애 이후 정상 확인된 연결만 관련 알림을 해결한다. 미확인 발송이나 수동 재개가 필요한 그룹은 자동으로 재개하지 않는다.

검증: 새 채널 공용 창 재사용, 일반 창 보호, 기존 탭 모으기와 부분 실패 보존, 보기/숨기기에서 발송 없음, 중지/미확인 상태 제한, 일시 읽기 실패와 실제 불일치 구분, 여러 채널별 알림 복구.
