# 발송 대기·초안 처리와 설정 보존

## 요청과 구현 선택

현재 계정이 실제 쿨다운 해제를 기다리는 동안 다음 계정으로 진행하지 않는다. 기존 조기 입력 준비를 유지하고, 전송 직전에 제한이 다시 생긴 경우에는 하나의 COMMIT 호출 안에서 기다린다. Enter를 보낸 뒤 초안이 남는 미확인 결과는 자동 재시도하지 않는다. 표시된 초안 잔류의 실제 원인은 현재 증거만으로 확정하지 않는다.

content는 양수·해제 관측을 확장 → 중앙으로 보고한다. 중앙은 현재 세션·실행·구성·탭·그룹과 관측 생존 시간을 확인하고 같은 시도를 유지한다. 해제 관측 뒤 새 승인을 받아 Enter 1회를 시도한다. 슬롯과 메시지 순서는 게시 확인 때만 갱신한다. 최대 지원 대기는 6시간 30초이고, 관측 유실·절전·중지는 차단한다.

이미 입력된 동일 문구는 붙여넣지 않고 재사용한다. 다른 일반 텍스트는 원문을 로컬 보관한 뒤 정확한 비교·교체 토큰으로 교체한다. 모든 비동기 경계에서 원문 변화·계정·대상·첨부·복합 입력을 다시 검사한다. 같은 발송 ID 및 미확인 시도를 중복 실행하지 않되 정상 반복 목록의 같은 본문은 금지하지 않는다. 보관 목록이 꽉 차거나 저장 실패면 원문을 덮지 않는다.

설정 화면은 저장값으로 초기화하고 항목별 편집 상태를 유지한다. 미저장 설정이 있으면 업데이트 자동 화면 새로고침을 보류한다. 테마는 브라우저별 시스템·라이트·다크 선택이며 기본 시스템, OS 변경 즉시 반영, 선택은 로컬 보존이다.

재연결은 저장된 대상만 복구한다. 현재 계정·기존 실행 중지 확인과 중앙·로컬 미확인 결과 검사를 통과한 경우에만 닫힌 전송 탭을 복구한다. 다른 페이지로 이동한 탭은 자동 이동시키지 않는다. 단계는 실제 계정·채널·구성 적용 결과로 대시보드에 표시한다. 실제 발송을 자동 시작하지 않는다.

긴 상세 모달은 화면 높이 내에 두고 내부 스크롤을 제공한다. 격리된 브라우저 검사가 시작 실패해 실제 화면·Discord 검증은 완료하지 못했다. 자동 시험·빌드 결과와 이 한계를 분리해 보고한다.
