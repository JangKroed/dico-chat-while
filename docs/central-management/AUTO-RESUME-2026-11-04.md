## 자동 재개 정책

시스템이 보호 목적으로 일시정지시킨 그룹에만 자동 재개 의도를 기록한다. 사용자 pause/stop, 전체 중지·긴급 중지는 예약된 자동 재개를 취소한다. 중지 적용 확인, 안정된 시간 기준, 현재 세션에서 새로 관찰된 모든 계정·채널과 최신 설정 적용이 확인되면 기존 실행 경로로 새 runId와 잠금을 확보한다. 중지되기 전 간격과 계정 쿨다운은 유지한다.

진행 중 또는 발송 결과가 불명확한 시도가 있으면 먼저 결과를 대조한다. 실행 차단 확인만으로 과거 미발송을 확정하거나 무조건 재전송하지 않는다. 복구 대상이 아닌 사용자 중지·일시정지를 시간 경과만으로 되살리지 않는다. 프로세스 재시작 후 과거 monotonic 근거를 재사용하지 않는다.

기존 버전에서 이미 멈춘 그룹에는 자동 중단 의도 정보가 없어 사용자 조작 여부를 상태만으로 구분할 수 없다. 이번 정책을 과거 paused 상태 전체에 일괄 적용하지 않는다. 실행 중 설치를 직접 변경하거나 실제 그룹을 시험 재개하지 않았다.
