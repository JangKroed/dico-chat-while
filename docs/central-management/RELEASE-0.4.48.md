# DICO 0.4.48 모두 실행 복구 예약

업데이트 전 중지로 이전 발송의 추가 실행이 차단됐어도, 게시 결과가 미확인인 경우가 있다. 이전 화면은 이 상태에서 모두 실행을 비활성화해 실행 의도를 중앙에 전달하지 못했다.

모두 실행은 실행 차단이 확인된 미확인 시도를 가진 그룹의 요청을 예약한다. 현재 세션의 중지 확인, 계정·채널 관찰, 설정 적용과 이전 결과의 자동 대조가 끝나면 기존 자동 복구 경로에서 시작한다. 같은 요청을 반복해도 중복 제어 명령을 생성하지 않는다. 별도 준비가 완료된 그룹은 기존 안전 조건에 따라 시작한다.

과거 발송을 성공 또는 실패로 추정하지 않으며, 결과가 확인되기 전에는 새 Enter나 다음 차례를 만들지 않는다. 근거가 계속 부족한 그룹은 복구 대기 상태를 유지한다. 뒤에 받은 전체 중지나 그룹 중지·일시정지는 예약을 취소한다.

회귀 테스트는 예약 접수, 중복 요청, 근거 확인 전 새 발송 차단, 자동 재개 및 후속 사용자 중지 우선권을 검증한다.
