# 기존 Discord 탭 재사용 (0.4.37)

## 사용자 동작

채널 연결 시 이미 열린 Discord 탭을 먼저 조회한다. 주소만 비교하지 않고 현재 로그인 계정·서버·채널을 실제로 확인한 뒤 같은 탭을 연결한다. 해당 탭이 없을 때만 전송용 창을 만든다. 기존 작성 중인 초안은 연결 단계에서 수정하지 않으며, 발송 시 기존 초안 보호 검사를 그대로 적용한다.

## 상태와 소유권

- `dicoCentralTabs`의 `ownership: 'adopted'`는 사용자가 열었던 탭이다.
- 재연결과 복구 시 해당 탭을 이동하거나 최소화하지 않는다.
- 계정·채널 연결 삭제 시 해당 탭은 닫지 않고 등록만 해제한다.
- 기존 연결 탭이 다른 화면으로 이동했으면 자동으로 덮어쓰거나 새 탭으로 미확인 작업을 우회하지 않는다.
- 사용자가 닫은 탭은 기존 연결 복구 정책에 따라 다른 일치 탭을 먼저 찾는다. 없으면 새로운 전송용 탭을 만든다. 새 탭은 프로그램 소유로 구분한다.

## 동시성·발송 안전

채널 연결은 같은 대기열에서 실행한다. 대기열 진입 시점의 세션과 초기화 세대를 확인해 이전 요청을 폐기한다. 실제 계정 확인 후 URL을 다시 조회하고, 미확인 발송과 실행 중인 콘텐츠가 있으면 연결을 변경하지 않는다. 탭 재사용 자체는 발송 승인을 부여하지 않는다.

## 검증

`tests/central-open-channel-reuse.test.js`와 창 관리·연결 복구 테스트에서 계정 불일치, 동시 연결, 초기화 경합, URL 변경, 초안 보존, 미확인 발송 차단, 소유권 유지 및 닫힌 탭 복구를 검증한다. 실제 사용자 Discord 계정으로 메시지를 보내는 검증은 수행하지 않는다.
