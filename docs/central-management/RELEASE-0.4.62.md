# DICO 0.4.62 — 계정 이동과 연결 유지 개선

## 사용자에게 보이는 변화

- Discord 계정을 다른 브라우저에서 명시적으로 저장하면 동일 계정의 기존 연결을 새 브라우저로 옮깁니다. 그룹 구성·순서와 메시지 설정을 유지합니다.
- 이미 생긴 중복 계정/채널은 설정을 보존하며 합칩니다. 이전 브라우저의 자동 관측이 중복 항목을 다시 만들지 않도록 이전 연결을 폐기합니다.
- 업데이트 설정의 최신 배포 확인/작업 완료 카드를 하나로 통합했습니다. 현재 버전·공식 배포·진행/실패·확인 시각을 한곳에 표시합니다.
- 확장 파일 점검/복구 중에도 현재 세션의 연결 유지 요청은 응답합니다. 발송 승인과 세션 변경은 파일 복구와 직렬로 처리합니다.

## 근거와 범위

2026-11-09 14:58:54 화면 기록(69초)에서 연결 완료, 브라우저 응답 대기, 로그인 계정 확인 중 상태가 반복되는 것을 확인했습니다. 새 UI는 적용되어 있지만 영상만으로 각 확장 및 Native host의 실행 버전이나 연결 종료 사유는 확정할 수 없습니다.

코드 재현에서는 Native host의 EXTENSION_STATUS 파일 검사 대기 뒤에 HEARTBEAT가 막히는 결함을 확인했습니다. 수정은 해당 재현 경로를 해결하며, 제보자 PC에서 발생한 모든 연결 변동의 원인이 같다는 뜻은 아닙니다. 실제 설치 후 운영 관측은 별도 확인이 필요합니다.

계정 교환 캡처의 중복 항목은 계정을 브라우저 ID와 함께 별도 등록하던 기존 동작으로 재현했습니다. 이제 명시적인 계정 저장을 이동 의도로 처리하며, 자동 관측만으로 다른 브라우저의 계정을 가져오지는 않습니다.

## 검증

자동 테스트 1,402개, TypeScript 검사/프로덕션 빌드, 문법·CSP 검사, SSR 및 실제 Chrome 전체 화면/진행 표시/업데이트 알림 검사를 통과했습니다. Windows·macOS 업데이터 CI 결과는 PR에 기록합니다. 실제 Discord 발송이나 운영 설치본 업데이트는 이 검증에서 실행하지 않습니다.
