# 반복 준비 실패 회복 검증

운영 0.4.54의 소스 기준은 `f1c3042`다. 이전 로컬 작업본에서 확인한 변경을 이 기준의 격리 체크아웃에 반영했다. 0.4.54가 추가한 초안 검사 실패 세부 코드도 그대로 전달한다.

같은 계정 차례에서 일시적인 Enter 전 실패가 세 번 누적되면, 중앙은 해당 실행의 입력이 차단됐다는 근거를 확인한 뒤 최소 그룹 간격을 지켜 다음 계정으로 진행한다. 미발송 문구는 그 계정의 다음 차례에 다시 사용한다. 중앙 타임아웃이나 구형 확장의 일반 거절 응답만으로는 차례를 넘기지 않는다. 구형 확장이 입력 전 읽기 단계에서 보고하는 초안 검사 실패의 기존 처리도 유지한다.

확장은 준비 거절을 보고하기 전에 해당 시도의 로컬 입력 권한을 닫고 저장한다. 거절 응답의 차단 확인은 중복 명령과 재시작 뒤에도 같은 값으로 전송한다. 이미 Enter를 요청한 시도는 이 준비 실패 처리로 확정할 수 없다.

## 검증

- 전체 자동화 테스트 1,355건 통과. 혼합 준비 실패, 최소 간격, 계정과 문구 순서, 늦은 요청, 단순 타임아웃, 구형 확장 응답, 차단 확인 재보고를 포함한다.
- 중앙 UI 컴파일, 확장 생성과 검사, React SSR 검증 통과.
- 임시 프로필을 사용한 Chrome과 Brave UI 검증은 두 브라우저 모두 시작 중 `SIGABRT`로 종료돼 완료하지 못했다.
- 빌드는 0.4.54 기준의 로컬 검증 산출물이다. 운영 런타임은 읽기 전용 조회에서 0.4.54로 응답했다. 운영 설치 교체, 배포, 실제 Discord 시험 발송은 수행하지 않았다.
