# 주소로 중앙 관리 페이지 접속하기

같은 공유기·내부망의 PC, Mac, 스마트폰 브라우저에서 중앙 PC의 주소를 입력하면 관리 화면에 접속할 수 있습니다. SSH나 다른 기기에 DICO 설치는 필요 없습니다. 중앙 PC의 DICO와 Discord 브라우저는 계속 켜 두세요.

## 처음 연결하기

1. 중앙 PC에서 **설정·도움말 → 내부망 접속**을 엽니다.
2. **내부망 접속 허용**을 켭니다. 현재 PC의 사설 IP를 자동으로 찾으며, 여러 주소가 있으면 사용할 네트워크를 선택합니다. 포트 기본값은 기존 로컬 관리 포트의 다음 번호이며 업데이트 때 임의 변경하지 않습니다.
3. 표시된 주소를 다른 기기 브라우저에 입력합니다. 예: `http://192.168.0.20:43128` — 이 값은 예시이며 화면에 나온 실제 주소를 사용하세요.
4. 중앙 PC에서 **연결 코드 만들기**를 누릅니다.
5. 다른 기기의 코드 입력 화면에 2분 안에 코드를 입력합니다. 코드는 한 번 사용하면 만료됩니다.

로그인하면 같은 작업 공간의 대시보드·메시지·계정·로그와 실행·중지 기능을 사용할 수 있습니다. 현재는 소유자 전체 관리 권한이며 기기별 제한 권한이나 다른 PC의 Discord 실행기 등록은 별도 기능입니다.

## 평소 사용과 종료

동일한 브라우저의 로그인은 최대 12시간 유지합니다. 중앙 프로그램 재시작·업데이트, 접속 끄기, 주소 변경 후에는 새 코드로 다시 로그인합니다. 원격 관리 탭을 닫아도 중앙 PC의 발송은 계속됩니다. 발송 중지는 대시보드에서 요청하고 적용 결과를 확인하세요.

**내부망 접속 끄기**는 다른 기기의 관리 연결과 세션을 폐기합니다. 기존 로컬 페이지와 확장프로그램의 연결, 발송 동작은 유지합니다. **모든 설정 초기화**를 하면 내부망 접속도 꺼집니다.

주소와 포트는 저장됩니다. 같은 네트워크 장치의 IP가 DHCP로 바뀌면 다음 프로그램 시작에서 새 사설 IP를 찾아 표시합니다. 다른 네트워크 장치로 임의 전환하지 않습니다.

## 접속이 안 될 때

- 두 기기가 같은 내부망인지 확인하세요. 서로 다른 장소라면 VPN으로 중앙 PC의 사설망에 연결한 뒤 VPN 주소로 접속합니다.
- 게스트 Wi-Fi의 기기 간 접근 차단과 중앙 PC의 방화벽을 확인하세요. 운영체제가 허용 여부를 물으면 사용할 사설 네트워크 범위에서 허용합니다. DICO는 방화벽이나 공유기 설정을 자동 변경하지 않습니다.
- 주소는 다른 기기의 `127.0.0.1`이 아니라 **중앙 PC 화면에 표시된 사설 IP 주소**를 사용합니다.
- 포트가 사용 중이면 중앙 화면에서 오류를 확인하고 내부망 포트를 변경한 뒤 새 주소를 사용합니다. 로컬 관리 포트와는 독립적입니다.
- 코드가 만료됐거나 사용됐다면 중앙 PC에서 새 코드를 만듭니다. 잘못된 입력이 반복되면 최대 2분 뒤 다시 시도합니다.
- 주소 복사가 안 되면 주소 입력란의 내용을 직접 선택해 복사하세요.

현재 직접 접속은 신뢰하는 내부망·VPN의 HTTP 연결입니다. 공유기 공인 포트 공개 용도가 아닙니다. 네이티브 브리지 인증이나 내부망 접속 설정 API는 이 원격 화면에서 사용할 수 없습니다.

기존 터널 방식을 원하는 경우에만 [고급 SSH 접속 안내](SSH-ACCESS.md)를 사용합니다.
