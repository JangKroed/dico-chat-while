# DICO 0.4.51 운영 화면과 업데이트 상태

일반 운영 화면 하나로 통일한다. 개발자 진단 모드 스위치, 해당 모드가 여는 화면과 수동 제보 진입점을 제거한다. 기존 진단 URL은 대시보드로 연결한다. 자동 오류 제보 동의와 운영 알림은 유지한다.

실행 요청을 받은 상태와 실제 발송이 진행 중인 상태를 구분한다. 게시 결과 확인을 기다리는 예약은 프로그램 재시작 뒤에도 일반 화면에서 표시한다. 게시 여부가 확정되지 않은 시도는 임의로 재전송하거나 차례를 건너뛰지 않는다.

설정의 업데이트 화면은 설치에 사용하는 공식 main의 중앙 패키지와 실행 중인 버전을 비교한다. 버전 확인은 설치와 동일한 Git 경로에서 파일을 읽고, 작업 파일은 정리한다. 새로고침은 현재 페이지를 나가지 않고 버전과 작업 상태를 다시 확인한다.

| 결과 | 표시 | 업데이트 실행 |
| --- | --- | --- |
| 실행 버전과 공식 버전이 동일 | 최신 업데이트 완료 | 비활성 |
| 공식 버전이 높음 | 새 업데이트 사용 가능 | 기존 중지·안전 조건 충족 시 활성 |
| 공식 버전이 낮음 | 공식 배포보다 높은 버전 사용 중 | 비활성 |
| 조회 중 또는 실패 | 확인 중 또는 확인하지 못함 | 비활성 |

업데이트 작업 완료 기록과 현재 공식 버전 확인 결과는 별개다. 브라우저 확장의 실제 연결 버전도 기존대로 별도 표시한다.
