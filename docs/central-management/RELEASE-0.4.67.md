# 0.4.67 — 브라우저 복원과 재연결

- 닫힌 프로필을 자동으로 열고 해당 실행기의 현재 세션 응답이 확인되면 브라우저 프로필을 기억합니다. 다음 복원에서 이 프로필을 브라우저의 최근 사용 목록보다 먼저 시도합니다. 기존 설치에 확인된 프로필이 없으면 첫 복원에서 후보를 순서대로 확인합니다.
- Chrome과 Brave 중 하나를 여전히 기다리고 있더라도, 이미 복구됐다 다시 끊긴 쪽을 별도로 다시 엽니다.
- 연결이 끊겨 시스템이 자동 일시정지한 그룹은 이전 발송 차단 응답을 받을 수 있도록 필요한 브라우저를 먼저 복원합니다. 사용자 중지는 자동 복원을 취소합니다.
- 프로필 확인만으로 발송 준비가 끝난 것으로 처리하지 않습니다. 계정, 채널, 설정 적용과 이전 실행 차단은 기존 검증 절차를 거칩니다.
