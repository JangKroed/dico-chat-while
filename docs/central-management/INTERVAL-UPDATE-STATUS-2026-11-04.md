# 간격 표시와 업데이트 완료 화면 정정

운영 DB를 mode=ro로 확인한 결과 그룹 11/22/33의 intervalMs는 모두 20000이었다. 15000으로 저장되는 현상은 재현하지 못했다. 카운트다운은 nextEligibleAt보다 5초 앞선 nextPreparationAt을 사용한다. 설정값을 바꾸지 않고 그룹 화면에 발송 가능까지와 입력 준비까지를 함께 표시한다. 20초 저장 후 15초 준비, 19.999초 허가 거절, 20초 허가 발급 회귀 검증을 추가했다.

업데이트 완료 상태에도 실시간 snapshot의 blockers를 '업데이트 전 남은 항목'으로 표시하던 문제를 수정했다. 완료 상태에서는 해당 목록을 숨기고 완료 문구에서 수동 버전 확인 요구를 제거한다. 미완료 상태 안내는 사용자 처리 지시 대신 현재 대기 상태를 설명한다. 연결 오류/장기 작업 상태 조회는 중단하지 않고 15초 간격으로 계속한다. 미확인 결과의 강제 확정이나 재전송은 하지 않는다. 이것은 모든 미확인 발송의 자동 해결을 구현했다는 의미가 아니다.

프로그램 운영 상태·실제 Discord 발송은 변경하지 않았다. 소스와 사전 빌드에 반영했으며 운영 프로그램에 적용/배포한 것으로 간주하지 않는다.
