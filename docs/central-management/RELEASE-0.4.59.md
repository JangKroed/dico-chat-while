# DICO 0.4.59 — 오류 처리 통합 업데이트

0.4.58의 슬로우모드 판독·전용 창 준비·초안 검사 진단·연결 단절 진단을 보존하고 아래 수정을 통합했다.

- 삭제한 채널의 탭이 다른 화면으로 이동했으면 탭은 보존하고 연결 해제를 완료한다. 소유 기록이 이미 제거된 탭도 재요청 때문에 무한 오류를 만들지 않는다. 다른 연결이 소유한 탭은 계속 보호한다.
- 연결 해제 직전에 중앙의 확정된 종료 기록을 대조해 오래된 로컬 준비 상태를 정리한다. 조회 실패·미확인 결과를 임의로 미발송 처리하지 않는다.
- 사용자가 요청한 중지로 발송 허가가 차단된 경우 명령 실패 사건을 중복 생성하지 않는다. 미확인 게시 기록은 보존한다.
- 중지 ACK보다 늦게 도착한 동일 제출 세션의 유효한 완료 영수증은 정상 완료로 반영한다. 발송 허가·실행 차단·정확한 제출 근거가 필요하며 사용자 중지를 해제하지 않는다.

관리 화면의 설정 → 업데이트는 GitHub main의 통합 소스를 사용한다. 중앙·확장·콘텐츠 버전은 0.4.59로 함께 빌드한다. 데이터 스키마 변경은 없다.

검증 결과는 INTEGRATION-0.4.59.md에 기록한다.
