## 확인한 코드 결함과 수정
- 공통 API 오류 안내가 일반 화면에서도 실행 기록의 수동 판정을 요구했다. 기본 안내를 현재 상태 설명으로 분리하고 상세 진단 절차는 개발자 모드에만 남긴다. 사용자 설정 선택이나 최초 로그인 같은 의사결정을 자동으로 대신하지 않는다.
- 입력 차단된 unknown 때문에 새 채널 탭 관찰을 거절하여 계정·채널 검증과 자동 조회가 막히던 경로를 복구했다. 원래 시도의 tabId/sessionId/시각은 바꾸지 않고, 새로 검증한 동일 계정·채널에서 게시 이력만 대조한다. 새 탭의 빈 입력창으로 과거 성공을 추측하거나 Enter를 재실행하지 않는다.
- 응답이 유실된 읽기 전용 RECONCILE은 30초 뒤 재조회할 수 있다. 누락 탭 복구는 기본 횟수 상한 없이 최대 60초 간격으로 계속하고 일시적인 미발송 준비 오류도 사용자 정지 전까지 복구한다. 결과가 불명확한 발송을 미발송으로 강제 변경하지 않는다.
- 긴 전송 재시도는 서버 시각 기준 경과 시간과 입력창 비움 확인 전 상태를 표시한다. 실제 반복 Enter의 직접 원인을 고쳤다는 의미는 아니다.
