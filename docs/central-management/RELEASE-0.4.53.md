# DICO 0.4.53 초안 판독 실패 시 다음 계정 진행

0.4.52 운영 기록에서 그룹 11은 미확인 차례를 넘기고 발송을 한 번 완료했다. 이후 다른 계정의 초안 검사 실패가 반복되며 발송 허가를 받지 못했다.

여러 계정이 있는 그룹은 허가 전 초안 판독이 연속 세 번 실패하면 다음 계정으로 넘어간다. 실패 기록은 미발송으로 남고, 초안과 해당 계정의 문구 순서는 유지한다. 다음 계정도 그룹 간격과 기존 슬로우모드 검사를 적용한다. 단일 계정은 기존 재시도를 유지한다.

회귀 테스트는 연속 세 번 실패, 문구 순서 보존, 최소간격 직전 차단, 다음 계정 준비를 확인한다.
