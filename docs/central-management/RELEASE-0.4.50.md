# DICO 0.4.50 이전 게시 이력 복구

브라우저에 이전 시도의 실행 기록이 없으면 자동 대조의 시작 시각이 현재 시각으로 설정되어 과거 게시를 찾지 못할 수 있었다. 또한 화면에 사용자 초안이 있거나 입력창이 바뀌면 게시 기록 자체의 확인까지 막혔다.

중앙에서 원래 시도의 허가 시각과 원래 실행 세션의 중지 적용 시각을 확인할 수 있으면, 그 사이의 게시만 읽기 전용으로 대조한다. 현재 로그인 계정·채널과 정확한 문구·작성자가 일치하는 최종 게시 한 건을 근거로 사용한다. 이전에 확인한 메시지보다 오래된 항목, 범위를 벗어난 게시, 중복 후보는 제외한다. 기존 초안을 바꾸거나 Enter를 다시 누르지 않는다.

이전 발송이 자동 확인되면 예약된 그룹 실행은 기존 자동 복구 절차를 따른다. 화면에서 읽을 수 있는 게시나 영수증이 없으면 결과는 미확인으로 보존된다.
