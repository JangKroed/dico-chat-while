# 그룹 선택 실행과 브라우저 탭 그룹

- 그룹 목록의 체크는 이번 선택 실행 대상이다. 활성 여부는 서버에 저장되며 모두 실행 대상을 결정한다.
- 기존 그룹은 enabled 필드가 없으면 활성으로 취급한다. 백업 내보내기/복원은 활성 설정을 보존한다.
- group.setEnabled {id,expectedVersion,enabled}는 버전을 검사한다. 비활성화는 자동 재개 의도를 지우고 실행 중인 그룹에 기존 중지 절차를 요청한다. 활성화 자체는 발송을 시작하지 않는다.
- service.startAll {groupIds?}는 ID가 생략되면 활성 그룹만, 명시되면 해당 그룹만 트랜잭션 내에서 검증·시작한다. 빈 선택, 삭제된 ID, 비활성 선택은 전체 요청을 거절한다. 전체 중지는 비활성 여부와 무관하게 유지한다.
- 신규 채널은 로그인 계정을 확인한 sourceTabId의 실제 windowId에 inactive 탭을 만든다. 동일 창 내 `DICO · 서버 ID` 탭 그룹을 재사용한다. tabGroups 권한을 추가했다.
- 새 탭은 grouped 소유권을 저장하여 자동 복구 시 사용자 창을 이동·최소화하지 않는다. 생성/그룹 지정 도중 실패·세션 변경 시 새 탭만 정리한다. 사용자 탭 재사용, 미확인 발송 보호, 생성 후 계정·채널 검증은 유지한다.
- 탭 그룹은 시각적 구분이며 계정/프로필을 옮기거나 만료된 로그인을 복구하지 않는다.

검증: 전체 1,252 테스트 통과, 추가 백업 복원 테스트 통과. TypeScript 및 production build 통과. 실제 Chrome UI smoke는 브라우저 시작 SIGABRT로 미완료. 실제 사용자 Discord 발송·실행·정지·설정 조작과 운영 업데이트는 수행하지 않았다.
