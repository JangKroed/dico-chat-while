# 0.4.34 연결 복귀 자동 처리

## 확인한 원인
0.4.33 UI는 지수 대기 후 연결 9회 실패 시 stopped=true로 종료했다. 횟수 제한은 정상이나 이후 네트워크가 복귀해도 online/focus/visibilitychange를 구독하지 않아 사용자의 재연결 버튼만 새 회차를 시작했다.

## 변경
네트워크 복귀 또는 화면 복귀 이벤트에서 offline 상태인 경우에만 새 유한 재연결 회차를 시작한다. 기존 8회 재시도 대기와 회차 종료를 유지하고 재무장은 30초 간격으로 제한한다. 이미 연결 중인 회차와 중복 실행하지 않으며 인증 만료를 자동 우회하지 않는다. 페이지 종료 시 리스너를 해제한다. 사용자 편집 내용과 발송 상태는 변경하지 않는다.

## 검증
신규 단위 회귀: 미구현 실패 확인 후 네트워크 복귀, 중복 이벤트, 인증 만료, 숨김 화면, 리스너 해제 통과.
실제 브라우저 회귀: 격리 Chrome에서 최초 API 연결 9회를 실패시키고 제한 종료 확인 뒤 online 이벤트만으로 대시보드에 복귀하는 경로를 추가했다. 실제 결과는 배포 검증 기록을 따른다.

## 범위
이 변경은 관리 화면 연결의 자동 복귀다. Discord 발송을 재개하거나 메시지를 재전송하지 않는다. 인증 만료는 실제 인증이 필요하며 이벤트 없이 서버만 돌아오는 경우 기존 회차 소진 상태에서 무한 폴링하지 않는다. 이전 전체 개선과 검증 한계는 RELIABILITY-2026-11-03.md에 기록되어 있다.
