# DICO 0.4.49 업데이트 종료 및 화면 복구

업데이트 중 설정 페이지에 접근하면 기존 서버가 종료 응답을 JSON으로 반환했다. 서버가 이미 닫힌 뒤에는 그 문서가 재연결을 시도할 수 없었다. 새 버전은 로컬 관리 화면 경로에 재연결 HTML을 제공한다. 같은 주소의 상태 요청이 성공하면 화면을 다시 열며 API의 503 JSON 계약은 유지한다.

교체 worker는 기존 런타임 설명자가 제거됐고 공유 관리 DB 잠금을 획득할 수 있는지 검사한다. 종료된 프로세스 번호가 남아 있다는 이유만으로 계속 대기하지 않는다. 실제 파일 교체 구간에서도 같은 잠금을 획득하고 유지한다.

종료 확인이 실패했으나 업데이트 종료 표식이 있고 런타임이 이미 내려간 경우, 파일 교체 없이 이전 설치를 다시 시작한다. 사용자 종료 표식이나 아직 사용 중인 잠금이 있으면 이 복구를 실행하지 않는다. 업데이트 결과는 교체 worker가 기록하며 종료 콜백이 뒤늦게 확정 상태를 덮어쓰지 않는다.

종료 확인과 복구 수정은 이 버전이 설치된 이후의 업데이트부터 동작한다. 기존 버전의 업데이트가 중간에 멈춰 서버가 종료된 상태라면 기존 설치의 관리 프로그램을 먼저 다시 열어야 한다.
