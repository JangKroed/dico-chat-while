# 0.4.30 자동 진단 및 발송 관찰 개선

업데이트 준비 중 네트워크 오류만 최대 두 번(2초, 5초 후) 자동 재시도한다. 적용/교체 단계는 무조건 반복하지 않는다. 도구 누락, 디스크/권한, 프로세스 차단, 배포 파일 불일치를 분류해 화면에 원인 코드와 단계를 표시한다. 실패해도 기존 프로그램과 설정을 보존한다.

브라우저 화면을 열지 않아도 실패 작업을 감시한다. 기존 자동 제보 동의를 따르며, 업데이트 진단은 본문/이름을 제외한다. 작업별 중복 방지 상태와 접수 번호는 재시작 및 outbox 정리 이후에도 유지한다. 자동 제보가 꺼져 있으면 사용자가 진단 보내기를 선택할 수 있다. 이메일 접수와 대기/전송 실패 상태를 구분한다. OS 보안 설정을 임의로 해제하지 않는다.

빠른 채팅에서 기본 아바타 계정 증명의 2초 만료를 실제 계정 변경으로 영구 기록하던 오류를 수정했다. 완료/재시도에는 여전히 새 계정 검증이 필요하다. 본인 전송 중 메시지가 가상 스크롤로 제거되어도 관찰 근거를 유지하여 Enter를 반복하지 않는다. 다른 작성자 채팅은 이 근거에 포함하지 않는다. 같은 시도를 관찰하고 제출한 입력창이 비워지면 완료한다.

검증: 두 발송 오류를 테스트로 먼저 재현했다. 증명 갱신 뒤 같은 입력창 유지, 전송 행 제거 뒤 30초 관찰 후 Enter 1회 완료, 실제 계정/채널 변경 차단, 자동 보고 HTTP 접수/중복 방지, 업데이트 재시도 소진/롤백과 구버전 오프라인 업데이트 호환성을 검증한다.
