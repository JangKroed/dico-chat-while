# DICO 0.4.68

## 자동 오류 메일

11월 9일에 생성된 제보가 이메일 중계의 하루 20건 한도에 걸려 여러 날에 걸쳐 전송됐습니다. 점검 당시 남은 자동 제보 27건은 모두 같은 날 생성됐고, 중계에서 한도 초과 응답을 받고 있었습니다.

- 생성 후 24시간이 지난 자동 이메일 제보는 재시도를 종료합니다. 보고서 파일과 전송함 기록은 보존합니다.
- 자동 이메일은 관리 프로그램 한 설치당 6시간에 한 번 전송을 시도합니다. 응답이 유실되거나 프로그램을 다시 시작해도 전송 간격을 적용합니다.
- 수동 제보와 이메일 중계를 사용하지 않는 직접 수신 서버에는 이 자동 이메일 정책을 적용하지 않습니다.

## 연결 관찰 로그

브라우저·계정 검증과 최근 확인 시각은 계속 갱신합니다. 동일한 상태의 반복 관찰을 로그에 쌓는 대신, 연결·계정·탭·설정 적용 상태가 바뀌는 시점에 관찰 이벤트를 기록합니다.
