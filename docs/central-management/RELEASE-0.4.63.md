# DICO 0.4.63 — 운영 상태 안내 개선

- 비활성 그룹을 시작 조건 검사 중으로 표시하지 않고, 사용 안 함·모두 실행 제외로 명시합니다.
- 시작할 수 없는 그룹은 실제 차단 사유를 표시합니다.
- 계정 수는 Discord ID 기준으로 중복을 제외하며, 이전 브라우저 등록은 별도 표시합니다. 수신 지연 시에는 확인 대기를 우선합니다.
- 현재 수신한 기록의 완료/미확인 건수를 함께 표시합니다. 미확인 결과를 성공으로 변경하지 않습니다.

검증: 테스트 1,403개, TypeScript/빌드, SSR, 실제 Chrome 1440/1000/390px 검사 통과. 운영 발송 설정은 변경하지 않았습니다. 본 버전은 화면 설명 개선이며 연결 지연의 모든 원인을 해결했다는 의미는 아닙니다.
