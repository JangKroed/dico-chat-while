# 0.4.64 — 변경된 탭의 자동 연결 복구

저장된 전송 탭에서 사용자가 다른 페이지로 이동하면 TARGET_MISMATCH로 연결 복구가 막히던 경로를 개선했습니다. 기존 페이지는 보존하고 현재 로그인 계정을 검증한 뒤 같은 채널의 다른 탭을 우선 재사용합니다. 기존 재사용 경로에 대상 탭이 없으면 새 전송 탭을 준비합니다.

같은 목적지의 탭이 일시적으로 미검증인 경우는 중복 탭을 만들지 않습니다. 이전 발송이 미확인인 경우, 계정 불일치, 세션 변경, 초기화 및 긴급 중지는 기존 차단을 유지합니다. 연결 복구는 발송 시작이나 허가를 의미하지 않습니다.

이번 릴리스는 자동 연결 재설계 중 탭 재탐색 단계입니다. 계정·브라우저 프로필 분리 UI와 닫힌 브라우저 프로필의 OS 자동 실행은 포함하지 않습니다. 운영 Discord 발송을 새로 시작하는 검증은 수행하지 않습니다.
