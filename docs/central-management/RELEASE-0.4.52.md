# DICO 0.4.52 미확인 발송에 대한 재개 선택

자동 대조가 게시 여부를 확정하지 못하면 실행 예약이 오래 대기할 수 있다. 대시보드의 **미확인 건 건너뛰고 재개**는 이전 시도의 실행 차단과 그룹의 실행 예약이 확인된 경우에 제공한다. 확인을 눌러야 현재 차례를 넘긴다.

이전 기록은 미확인 상태와 건너뛴 시각을 보존한다. 과거 시도를 다시 실행하거나 성공·미발송으로 바꾸지 않는다. 늦게 도착한 결과는 현재 차례에 적용하지 않는다. 다음 차례는 기존 그룹·계정 간격과 연결·설정 확인을 거친다. 다시 중지하면 기존 예약 취소 규칙이 적용된다.

확장은 중앙의 건너뛰기 표식을 받으면 과거 실행을 닫되 게시 결과는 미확인으로 유지한다. 새 차례의 초안 확인·보존 규칙은 기존 경로를 사용한다.
