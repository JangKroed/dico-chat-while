# DICO 0.4.52 미확인 발송 자동 건너뛰기

실행 의도가 남은 그룹에서 발송 결과가 미확인이면 기존 시도의 실행 차단을 먼저 확인한다. 호환 확장이 연결되어 있으면 과거 게시물을 조회하지 않고 미확인 기록과 건너뛴 시각을 보존한다. 이후 다음 계정 및 해당 계정의 다음 문구 차례를 적용한다. 다음 시도도 미확인이면 같은 절차를 반복한다. 늦은 결과는 현재 차례를 변경하지 않으며 사용자 중지는 재개 예약보다 우선한다.

다음 시도는 연결·설정·초안·그룹 및 계정 간격을 확인한다. 페이지가 읽은 Discord 쿨다운이 남아 있으면 같은 차례에서 대기한다. Enter 전 쿨다운 판독이 일시적으로 실패하면 실행 차단과 미제출 근거가 있는 경우 준비를 다시 시도한다. 구버전 확장은 새 종료 표식을 이해할 수 없어 기존 대조 경로를 유지한다.

합성 테스트에서 연속 두 건 건너뛰기, 차단 확인 전 보류, 최소 간격, 사용자 중지 우선, 슬로우모드 대기 및 해제를 검증한다.
