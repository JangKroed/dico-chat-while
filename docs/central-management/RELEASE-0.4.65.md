# 0.4.65 — 계정 배정과 브라우저 프로필 자동 준비

## 변경

- 등록 계정 카드에서 사용할 브라우저 연결을 별도로 선택합니다. 기존 그룹·메시지 배정을 보존하며 이전 계정 검증은 무효화합니다. 관련 그룹 실행·미확인 발송·연결 준비 중에는 이동하지 않습니다.
- 브라우저 카드에서 호스트가 발견한 Chrome/Brave 프로필을 한 번 지정합니다. 프로필 이름만으로 로그인 계정을 추정하지 않으며 실제 Discord 계정 확인을 거칩니다. 로그인과 추가 인증은 자동 수행하지 않습니다.
- 모든 참여 브라우저에 자동 실행 프로필이 지정된 그룹은 오프라인 상태에서도 시작을 요청할 수 있습니다. 요청을 중앙에 보존하고 연결·계정·채널·설정 ACK 이후 기존 스케줄러로 실행합니다.
- 연결된 프로필은 재사용합니다. 연결이 없는 등록 프로필은 지정된 실행 파일과 프로필로 Discord 웹을 엽니다. 같은 연결 요청은 하나로 합치고 성공 후 확장 응답이 늦다는 이유로 창을 반복 생성하지 않습니다. 실행 실패·프로필 누락은 30초마다 재확인합니다.
- 준비 중 중지/모두 중지/비활성화를 실행하면 예약을 취소합니다. 준비 중 업데이트 교체와 그룹 편집은 차단합니다.
- 기존 30초 그룹 간격·5초 조기 준비·중복 방지·실제 계정 검증과 늦은 세션 응답 차단은 기존 중앙 엔진에서 수행합니다.

## 지원 범위와 검증 한계

현재 중앙 PC의 표준 설치 경로 Chrome/Brave 프로필을 지원합니다(macOS /Applications, Windows Program Files). 원격 PC 전원 켜기, 프로필별 로그인 자동화, 비표준 설치 경로 자동 탐색은 제공하지 않습니다. 잘못된 프로필을 선택하면 기대 계정의 연결을 기다리며 다른 계정으로 발송하지 않습니다.

로컬 프로필 발견, 실행 인자·단일 요청·중지 경쟁·실패 처리, 계정 이동과 재연결→계정 관찰→설정 ACK→예약 시작을 자동 검증했습니다. 사용자 운영 브라우저를 새로 열거나 실제 Discord 발송을 시작하지 않았습니다. 격리 Chrome 화면 검사는 프로세스가 SIGABRT로 종료되어 완료하지 못했습니다.

구형 확장 동시 실행 충돌 검토는 LEGACY-COEXISTENCE-REVIEW-2026-11-09.md에 별도 기록했습니다. 구형 확장은 수정하지 않았고 이 버전이 구형 실행기를 자동 차단한다고 주장하지 않습니다.
