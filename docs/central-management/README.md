# DICO 중앙관리 개편 기획

작성: 2026-10-30 KST · 상태: 승인된 제품 방향의 상세 설계 · 제품 구현 전

한 사람이 PC 한 대에서 여러 Chromium 브라우저·프로필로 Discord 계정과 채널을 운영하는 로컬 관리 도구다. macOS와 Windows 사용자는 각자 자기 PC에서 자기 메시지·설정·기록을 관리한다.

## 문서 읽는 순서

1. [제품 기획서](PRODUCT.md): 범위, 사용 순서, 메시지와 발송 정책, 인수 기준.
2. [화면별 UI/UX 명세](UX.md): 화면 배치, 버튼 동작, 빈 화면과 오류·복구 흐름.
3. [기술 설계와 개발 로드맵](ARCHITECTURE.md): 자동 연결, 통신·저장·마이그레이션, 단계별 완료 조건.
4. [로그·그래프·알림 명세](OBSERVABILITY.md): 실시간 현황, 지표 정의, 알림 센터와 OS 알림, 집계·보존 정책.
5. [개발판 구현 현황](IMPLEMENTATION.md): 실제 제공 기능, 검증 결과와 출시 전 남은 작업.

## 이번 대화에서 확정된 내용

- PC 한 대에 중앙관리 프로그램과 여러 확장을 연결한다.
- macOS·Windows 모두 대상이고 Chrome·Brave 등 Chromium 브라우저를 사용한다.
- 각 사용자의 메시지와 데이터는 따로 관리한다.
- IP·포트·연결 토큰의 수동 입력을 기본 사용 흐름에서 없앤다.
- 중앙 페이지에 대시보드, 메시지 관리, 채널별 선택·적용, 발송 그룹, 기록, 설정과 튜토리얼을 둔다.
- 메시지를 여러 개 준비하고 추가·수정·삭제한 뒤 채널별로 골라 적용한다.
- 여러 계정의 발송 순서는 중앙에서 관리한다.
- 로그와 진행 상태를 페이지·대시보드에서 바로 확인하고 그래프로 분석한다. 필요한 문제는 OS 알림으로 알린다.

## 설계에서 정한 기본값

아래는 대화에서 직접 지정한 값이 아니라 요구사항을 구현하기 위한 제안이다. 구현 단계의 검증 결과에 따라 문서와 함께 조정한다.

| 항목 | 기본 설계 |
| --- | --- |
| 실행 형태 | OS 사용자별 로컬 백그라운드 프로그램 + 브라우저에서 여는 중앙 페이지 + 공통 Chromium 확장 |
| UI 기술 | React·TypeScript·Vite, 로컬 서비스가 빌드 파일 제공 |
| 로컬 서비스 | TypeScript·Node.js 런타임을 설치 패키지에 포함; 사용자에게 Node.js 설치 요구 안 함 |
| 저장 | SQLite 트랜잭션, 기존 JSON·브라우저 데이터의 명시적 가져오기 |
| 연결 | Native Messaging으로 자동 발견·초기 연결; 확장 명령·이벤트는 네이티브 브리지 경유 |
| 실시간 화면 | 로컬 인증 세션 + SSE, 변경 명령은 인증된 POST |
| 로그·알림 | 같은 이벤트 기반의 화면·그래프·알림 센터; 중요한 문제는 선택한 로컬 OS 알림으로 전달 |
| 최초 실행 | 조정기 자동 실행; 로그인 시 자동 시작은 설치 안내에서 선택 |
| 재시작 후 발송 | 자동 재연결은 하되 발송은 사용자의 재개 후 실행 |
| 메시지 적용 | 수정본 저장과 채널 적용 분리; 준비 중·전송 중 문구는 고정 |
| 배포 검증 | macOS Apple Silicon·Intel, Windows x64의 Chrome·Brave 우선; 나머지는 호환 확인 후 지원 |

## 현재 구현과 구분

기존 교대 공지 확장은 0.3.0이며, 별도 `central/` 경로에 중앙관리 0.4 개발판을 구현했다. 중앙 UI·메시지 보관함·자동 연결·로컬 서비스·발송 엔진의 기본 기능이 준비되어 있다. 상세 기획 전체의 완료나 모든 OS에서의 출시 검증을 의미하지는 않으며 [실제 구현 범위](IMPLEMENTATION.md)를 우선 확인한다. 기존 확장 ID와 데이터는 새 전용 실행기로 자동 교체하지 않는다.

기존 설계 기록은 [0.3.0 조정기 설계](../superpowers/specs/2026-10-30-coordination-design.md)에 보존한다. 새 버전 개발에는 이 폴더의 명세를 우선한다. 실제 계정으로 시험 메시지를 보내는 일은 문서 작성·자동 테스트에 포함하지 않는다.
