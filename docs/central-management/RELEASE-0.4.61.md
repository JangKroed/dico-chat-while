# DICO 0.4.61 — 새 업데이트 알림

관리 프로그램 실행 중 5분 간격으로 새 배포를 확인한다. 설정 화면을 열지 않아도 모든 화면 상단에 새 버전과 업데이트 안내를 표시한다. 업데이트 확인 버튼은 설정으로 이동하며 이미 설정을 보고 있는 경우 최신 버전을 다시 조회한다. 설치는 사용자가 업데이트 실행을 선택해야 시작한다.

- 화면 안내는 OS 알림 설정과 독립적이다. ‘나중에’를 선택한 버전은 이 브라우저에서 다시 표시하지 않고 이후 새 버전은 다시 안내한다. 일시적인 조회 실패로 이미 확인한 새 버전 안내를 지우지 않는다.
- OS 알림은 기존 notificationsEnabled와 방해금지 시간을 따른다. notification-state.json에 버전별 요청 이력을 저장해 재시작·중복 조회에도 같은 버전은 한 번만 요청한다. 꺼진 알림이나 방해금지 시간에는 이력을 소비하지 않는다. OS 정책에 따라 표시가 차단될 수 있으며 화면 안내는 계속 제공한다.
- 버전 조회는 발송/중지와 별개로 실행한다. 종료 시 진행 중인 읽기 전용 조회는 기다리지 않고 늦은 결과를 버린다. 이미 시작한 알림 이력 저장은 종료 전에 마친다.
- 해당 기능은 0.4.61을 설치한 사용자부터 동작한다. 이전 설치본에 원격으로 새 알림 기능을 주입하지 않는다.

검증: 전체 Node 테스트 1,382개 통과(실패/건너뜀 0), TypeScript/Vite·prebuilt·확장·JS/CSP 검사 통과. 격리 Chrome에서 전역 알림, 설정 이동/동일 화면 재조회, 버전별 닫기·재시작, 새 버전 재안내, 조회 실패 시 보존, 설치 버전 확인 후 배너 제거, 모바일 배치 확인. 기존 전체 UI·진행 상태 브라우저 검사도 통과했다. 실제 OS 알림 발송은 mock으로 검증했으며 운영 사용자에게 시험 알림을 발송하지 않았다.
