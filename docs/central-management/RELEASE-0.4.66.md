# 0.4.66 — Discord 계정 기준 자동 연결

- Discord 계정과 브라우저 프로필을 따로 관리합니다. 브라우저에서 현재 로그인한 계정을 확인하면 해당 계정의 기존 채널, 문구와 그룹 순서를 유지하며 실행 연결을 정리합니다.
- 같은 계정이 여러 프로필에 열려 있으면 기존에 검증된 그룹 연결을 우선 사용합니다. 연결이 바뀌면 이전 전송용 연결과 중복 등록을 정리합니다. 진행·미확인 발송이 남아 있을 때는 이전 입력과 결과를 보호합니다.
- 실행을 누르면 열린 브라우저의 채널부터 재사용합니다. 필요한 Chrome·Brave가 닫혔으면 DICO 설치 흔적이 있는 프로필을 최근 사용 순으로 확인합니다. 예전에 저장한 실행 프로필이 있으면 먼저 확인하고, 필요하면 같은 브라우저의 다른 후보를 확인합니다.
- 실제 계정과 채널, 설정 적용이 확인된 그룹부터 실행합니다. 로그인 만료와 2단계 인증은 브라우저에서 처리하며, 확인이 끝날 때까지 해당 계정에 발송 권한을 부여하지 않습니다.
